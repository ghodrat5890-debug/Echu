# ECHU — Website Growth Project

This repository is the source of truth for the technical, architectural, SEO, UX and agent-operation documentation of echu.ir.

## Project roles

- **Owner:** ECHU / final business and publishing decision
- **ChatGPT:** strategy, architecture, prioritization, QA and governance
- **Claude:** content and SEO-content production
- **Grok:** creative/design analysis and implementation support
- **ECHU Website Agent:** controlled WordPress/Avada execution and operational QA
- **GitHub:** version control, documentation and change history

## Current status

The repository starts as an empty control/documentation layer. It does **not** represent the live WordPress site code yet.

## Safety rule

No destructive or production publishing action is autonomous. High-risk changes require explicit approval and a reversible execution plan.
